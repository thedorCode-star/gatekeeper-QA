# Gatekeeper QA Website

Next.js (App Router) + TypeScript + Tailwind CSS marketing site for Gatekeeper QA.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Deploy target: Vercel (Phase 1 / Phase 5)
